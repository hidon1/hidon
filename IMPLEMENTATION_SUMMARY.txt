🎮 HOW IT WORKS
═══════════════════════════════════════════════════════════════

GAME FLOW:
----------
1. Player 1 clicks "ראש בראש" → Creates room
2. Player 1 copies shareable link
3. Player 2 opens link → Joins room
4. Game starts automatically when both connected
5. 30 random questions from all 10 JSON files
6. 20-second timer per question
7. Both players see same question simultaneously
8. Answers saved with timestamps
9. Score calculated: time points + speed bonus
10. After 5 minutes or all questions: Winner declared
11. Winner receives all coins

SCORING SYSTEM:
--------------
• Time Points: Remaining seconds when answered correctly
  Example: Answer at 15s remaining = 15 points

• Speed Bonus: +4 points to faster correct answer
  Only if both answer correctly

• Point Distribution:
  - Winner takes ALL points from BOTH players
  - Example: Player 1 scores 120, Player 2 scores 80
  - Total: 200 points
  - Winner receives all 200 points
  - NO COINS involved in H2H games

• Victory Tracking:
  - Wins stored in Firebase user profile (h2hWins)
  - Displayed in main dashboard with 🏆 icon
  - Losses tracked in h2hLosses
  - Ties tracked in h2hTies
  - Total points in h2hPoints

🚀 HOW TO USE

FOR PLAYERS:
-----------
1. Open the game
2. Click menu (☰)
3. Select "שחק ראש בראש"
4. Choose option:

6. Wait for them to join
7. Game starts automatically!

• Database path: h2hRooms/{roomId}

🔧 FIREBASE CONFIGURATION
═══════════════════════════════════════════════════════════════

Database Structure:
h2hRooms/
  └─ {roomId}/
      ├─ status: "waiting" | "ready" | "playing" | "finished"
      ├─ createdAt: timestamp
      ├─ currentQuestion: number (0-29)
      ├─ players/
      │   ├─ {playerId1}/
      │   └─ {playerId2}/
      ├─ questions: array[30]
      └─ answers/
          └─ {questionIndex}/
              ├─ {playerId1}/
              └─ {playerId2}/

users/
  └─ {userId}/
      ├─ displayName: string
      ├─ avatar: string
      ├─ coins: number (for main game only)
      ├─ h2hWins: number (H2H victories - displayed in dashboard)
      ├─ h2hLosses: number (H2H defeats)
      ├─ h2hTies: number (H2H draws)
      └─ h2hPoints: number (Total H2H points accumulated)
